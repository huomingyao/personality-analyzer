## 各类型 wing 组合详解

### 1号 wings

- **1w9**：沉思的完美主义者
  - 更安静、更沉思
  - 内在有怒气但不外露
  - "安静的愤怒"

- **1w2**：热心的完美主义者
  - 更外向、更有爱心
  - "我在帮你变好"
  - 帮助他人时也要求完美

### 2号 wings

- **2w1**：助人的完美主义者
  - 有原则的助人
  - "帮你是因为这是对的"

- **2w3**：成功的给予者
  - 更目标导向
  - "我是最有用的人"

### 3号 wings

- **3w2**：魅力的成就者
  - 更温暖、更有魅力
  - "大家都爱我"

- **3w4**：原创的成就者
  - 更独特、更有创意
  - "我不只是成功，我还独特"

### 4号 wings

- **4w3**：成功的浪漫主义者
  - 追求独特成就
  - "我要做唯一的成功者"

- **4w5**：内省的浪漫主义者
  - 更安静、更深刻
  - "我是最深沉的那一个"

### 5号 wings

- **5w4**：反叛的探索者
  - 更情绪化、更独特
  - "我是最独特的研究者"

- **5w6**：忠诚的探索者
  - 更焦虑、更谨慎
  - "我要验证才安全"

### 6号 wings

- **6w5**：防守型的忠诚者
  - 更内敛、更理性
  - "让我先研究清楚"

- **6w7**：积极的忠诚者
  - 更乐观、更冲动
  - "未来会很棒！"

### 7号 wings

- **7w6**：忠诚的热情者
  - 更焦虑、更需要保证
  - "你会陪我去吗？"

- **7w8**：强势的热情者
  - 更直接、更控制
  - "跟我来！"

### 8号 wings

- **8w7**：乐观的保护者
  - 更冲动、更爱扩张、"扩张！扩张！"
  - 充满活力，行动先于思考

- **8w9**：温和的保护者
  - 更平静、更稳健、"别惹我"
  - 表面平静但有底线

### 9号 wings

- **9w8**：坚定的和平主义者
  - "温和的石头"
  - 平静但有底线

- **9w1**：理想主义的和平主义者
  - "有原则的老好人"
  - 随和但追求正确

## 各类型 arrow 路径详解

### 压力线方向（Stress）

在压力和不安全感增加时，"退化"到箭头指向的类型：

| 当前类型 | 压力下表现 | 退化原因 |
|----------|------------|----------|
| 1号 | 7号特质：失控享乐、逃避责任 | "我不够好" → 干脆不管了 |
| 2号 | 8号特质：强硬、控制 | "没人领情" → 干脆不给了 |
| 3号 | 9号特质：懈怠、拖延 | "太累了" → 干脆不做 |
| 4号 | 2号特质：过度付出、討好 | "没人懂我" → 去讨好 |
| 5号 | 8号特质：防御性强势 | "被侵犯" → 先攻击 |
| 6号 | 3号特质：盲目行动、急于求成 | "焦虑" → 乱行动 |
| 7号 | 1号特质：批判、愤怒 | "不爽" → 爆发 |
| 8号 | 5号特质：退缩、封闭 | "受伤" → 躲起来 |
| 9号 | 6号特质：焦虑、怀疑 | "失去连接" → 焦虑 |

### 轻松线方向（Integration）

在轻松和成长时，"进化"到箭头指向的类型：

| 当前类型 | 轻松下表现 | 进化原因 |
|----------|------------|----------|
| 1号 | 4号特质：深度、独特 | "允许自己不完美" → 回归真实 |
| 2号 | 4号特质：关注自己 | "先爱自己" → 回归自我 |
| 3号 | 6号特质：忠诚、可靠 | "真正的朋友" → 回归关系 |
| 4号 | 1号特质：理想主义、行动 | "我可以变好" → 回归行动力 |
| 5号 | 7号特质：开放、参与 | "分享也无妨" → 回归连接 |
| 6号 | 9号特质：放松、接纳 | "相信就好" → 回归平静 |
| 7号 | 5号特质：专注、深耕 | "深入" → 回归深度 |
| 8号 | 2号特质：温和、关爱 | "展示柔软" → 回归爱心 |
| 9号 | 3号特质：行动、实现 | "我可以" → 回归行动力 |

## 各类型的"我很好"和"我不好"

每个类型都有一个内在的"自我价值"故事：

| 类型 | "我很好"時 | "我不好"時 |
|------|-------------|------------|
| 1号 | "我是正确的" | "我是错误的" |
| 2号 | "我是有价值的" | "我不被需要" |
| 3号 | "我是成功的" | "我是失败的" |
| 4号 | "我是独特的" | "我没有 Identity" |
| 5号 | "我是能的" | "我是无能的" |
| 6号 | "我是安全的" | "我会失去依靠" |
| 7号 | "我是满足的" | "我会被剥夺" |
| 8号 | "我是强大的" | "我会被控制" |
| 9号 | "我是连接的" | "我会失去连接" |

## 各类型的"基本议题"

每个中心有一个共同的基本议题：

### 脑中心（5、6、7）

**共同议题**："我该相信什么？"

| 类型 | 答案 |
|------|------|
| 5号 | 我相信我所知道的（知识） |
| 6号 | 我相信我所依赖的（权威） |
| 7号 | 我相信未来的可能性（希望） |

### 心中心（2、3、4）

**共同议题**："我值不值得被爱？"

| 类型 | 答案 |
|------|------|
| 2号 | 只要我帮助别人，我就值得被爱 |
| 3号 | 只要我成功，我就值得被爱 |
| 4号 | 只要我独特，我就值得被爱 |

### 腹中心（8、9、1）

**共同议题**："我可以保护自己吗？"

| 类型 | 答案 |
|------|------|
| 8号 | 我要变得强大来保护自己 |
| 9号 | 我要保持和平来保护自己 |
| 1号 | 我要做正确的事来保护自己 |
