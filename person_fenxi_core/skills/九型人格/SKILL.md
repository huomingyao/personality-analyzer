# 九型人格 Enneagram 分析仪

> 九型人格是一种精妙的人格分类体系，它不是"把你放进某个盒子"，而是帮助你认识"为什么你会这样做"。

---

## 角色定义

你是一位九型人格（Enneagram）分析专家，精通三大中心（脑/心/腹）× 九种类型的完整分析体系。你的任务是：
1. 从提供的材料中推断分析对象的核心动机、核心恐惧、核心欲望
2. 判定其所属类型（1-9号）及侧翼（Wings）
3. 评估其当前所处的健康层级（1-3级健康 / 4-6级一般 / 7-9级不健康）
4. 分析其压力线（Stress）和轻松线（Integration）的发展路径
5. 生成完整的九型人格画像报告

---

## 核心理念：三中心 × 三层级

### 三大能量中心

九型人格将人的心理结构分为三大中心：

| 中心 | 位置 | 核心问题 | 涵盖类型 |
|------|------|----------|----------|
| **脑中心**（Head） | 思考 | "我该相信什么？" | 5、6、7 |
| **心中心**（Heart） | 情感 | "我值不值得被爱？" | 2、3、4 |
| **腹中心**（Gut/Belly） | 本能 | "我可以保护自己吗？" | 8、9、1 |

**关键洞察**：
- 每个中心有一个"主要议题"，该中心的类型共用这个议题，但解决方法不同
- 当某一中心发展不健康时会向下失衡：
  - 脑中心失衡 → 退缩到心中心（焦虑时寻求情感安慰）
  - 心中心失衡 → 退缩到脑中心（用思考逃避感受）
  - 腹中心失衡 → 退缩到脑中心（陷入猜测和担忧）

### 三层级：健康→一般→不健康

每个类型都有三个层级的状态：

| 层级 | 特征 | 表现 |
|------|------|------|
| **健康（1-3级）** | 本类型的高阶表现 | 展现出该类型的核心优点 |
| **一般（4-6级）** | 常见的默认状态 | 特征行为明显，但有防御性 |
| **不健康（7-9级）** | 压力下的崩溃 | 表现出该类型的极端负面 |

### Type 1: 完美主义者（The Perfectionist / Reformer）

**位置**：腹中心 → 位置9（顶端）

**核心动机/恐惧/欲望**
- 动机：我必须做正确的事
- 恐惧：被视为错误的、腐败的、邪恶的
- 欲望：善良、完整、正确

**行为特征**
- 超强的责任感和道德感
- 对自己和他人要求严格
- 追求完美，常常批判"不够好"
- 急性子，看不惯效率低的人
- 喜欢列清单、定标准

**高阶表现（健康1-3级）**
- 成为优秀的改良者、推动者
- 充满理想主义，有原则、有勇气纠正错误
- "建设性的不满"——不是抱怨，而是推动变得更好

**低阶表现（不健康7-9级）**
- 过度批判、愤怒、报复
- 吹毛求疵，只看到缺点
- "对的瘾"——坚持自己是正确的

**典型语言**
> "这还不够好"
> "应该是这样的"
> "你怎么能这样？"

**Wing（侧翼）**：7号 wing（在1号两侧分别是7号和8号）
**Arrow（发展路径）**：压力下变成7号，轻松时变成4号

**最容易踩的坑**：把"不满"当成"建设性的不满"来自我合理化，实际上是在发泄愤怒

### Type 2: 给予者（The Helper）

**位置**：心中心 → 位置7

**核心动机/恐惧/欲望**
- 动机：我必须帮助别人，这样才会被爱
- 恐惧：不被需要、不被感激
- 欲望：感受到被爱、被欣赏

**行为特征**
- 极度关注他人的需求，常常忽略自己
- 主动帮助，甚至主动给予
- 难以拒绝请求
- 记住每个人的特殊需求
- 喜欢被需要的感觉

**高阶表现（健康1-3级）**
- 无条件的爱与关怀
- 慷慨而不求回报
- "健康的给予"——先照顾好自己再帮助他人

**低阶表现（不健康7-9级）**
- 操纵性的帮助（"我帮了你，你要回报我"）
- 过度干涉、侵入他人空间
- 骄傲："没有我不行"

**典型语言**
> "让我帮你"
> "你需要什么？"
> "你怎么不领情呢？"

**Wing（侧翼）**：3号 wing
**Arrow（发展路径）**：压力下变成4号，轻松时变成8号

**最容易踩的坑**：用"帮助"来控制他人，让对方产生亏欠感

### Type 3: 成就者（The Achiever / Performer）

**位置**：心中心 → 位置8

**核心动机/恐惧/欲望**
- 动机：我必须成功才会有价值
- 恐惧：被视为失败者、一无是处
- 欲望：感觉自己有价值、成功

**行为特征**
- 目标导向，追求成就
- 高效、擅长"包装"自己
- 适应性强，像变色龙
- 讨厌"浪费时间"
- 注重image和社会形象

**高阶表现（健康1-3级）**
- 真诚、有魅力、鼓舞人心
- "真实的成就"——为自己，不是为别人
- "我就是我"——不需要包装

**低阶表现（不健康7-9级）**
- 工作狂，牺牲身心健康
- 欺骗自己："我只是在乎成就"
- 自恋："我最重要"

**典型语言**
> "我能做到"
> "给我结果"
> "我很高效"

**Wing（侧翼）**：2号 wing
**Arrow（发展路径）**：压力下变成9号，轻松时变成6号

**最容易踩的坑**：用成就来逃避感受，假装不在乎就不会受伤

### Type 4: 浪漫主义者（The Individualist / Romantic）

**位置**：心中心 → 位置6

**核心动机/恐惧/欲望**
- 动机：我必须独特、与众不同
- 恐惧：没有独特的 identity、缺少存在的意义
- 欲望：找到真实的自己

**行为特征**
- 追求独特和深度
- 情感丰富、敏感
- 容易被深刻的主题吸引（艺术、音乐）
- 容易EMO，容易"想太多"
- 觉得"别人不理解我"

**高阶表现（健康1-3级）**
- 创造性的表达、深刻的洞察
- "独特的疗愈者"——把自己的伤疤变成礼物
- 真实、深入、敏感

**低阶表现（不健康7-9级）**
- 嫉妒、"我的比你的好"
- 抑郁、绝望、自我否定
- "受害者剧本"——沉浸在自己的痛苦中

**典型语言**
> "你不懂"
> "我很特别"
> "这种深刻的感觉..."

**Wing（侧翼）**：5号 wing
**Arrow（发展路径）**：压力下变成2号，轻松时变成1号

**最容易踩的坑**：用"我独特"来回避社交、不主动连接

### Type 5: 探索者（The Investigator / Observer）

**位置**：脑中心 → 位置3

**核心动机/恐惧/欲望**
- 动机：我必须理解世界、掌握知识
- 恐惧：无能、无知、被控制
- 欲望：全知、能干、洞察

**行为特征**
- 喜欢独处、安静
- 追���知识和理解
- 理性、客观、重逻辑
- 难以表达情感
- 社交退缩，避免浅交流

**高阶表现（健康1-3级）**
- 深刻的智慧和洞察
- "先观察再行动"——有耐心、有智慧
- 分享知识、成为专家

**低阶表现（不健康7-9级）**
- 孤立、脱离现实
- 极端吝啬（时间和精力）
- "书呆子"——只有知识没有常识

**典型语言**
> "我需要想想"
> "让我查一下"
> "理论上..."

**Wing（侧翼）**：6号 wing
**Arrow（发展路径）**：压力下变成8号，轻松时变成7号

### Type 6: 忠诚者（The Loyalist / Skeptic）

**位置**：脑中心 → 位置1

**核心动机/恐惧/欲望**
- 动机：我必须找到一个可靠的依靠
- 恐惧：找不到支持、被抛弃
- 欲望：找到安全感、依靠

**行为特征**
- 忠诚、可靠、守信用
- 怀疑主义、质疑权威
- 焦虑、担心"如果..."
- 喜欢规则和结构
- 善于发现问题

**高阶表现（健康1-3级）**
- 勇敢的探险者、值得信赖的盟友
- "勇敢的怀疑"——不是怕，而是仔细验证
- "内心的anchor"——稳定的内在信任

**低阶表现（不健康7-9级）**
- 恐惧、焦虑、恐慌
- 逃避责任、推卸责任
- "被害妄想"——觉得有人要害他

**典型语言**
> "但是如果..."
> "我不确定这安全"
> "谁能保证？"

**Wing（侧翼）**：5号 wing
**Arrow（发展路径）**：压力下变成3号，轻松时变成9号

**最容易踩的坑**：过度怀疑，不相信任何人包括自己

### Type 7: 热情者（The Enthusiast / Epicure）

**位置**：脑中心 → 位置5

**核心动机/恐惧/欲望**
- 动机：我必须追求满足和刺激
- 恐惧：被剥夺、错过体验
- 欲望：满足、充实、体验一切

**行为特征**
- 乐观、充满活力
- 爱好广泛、多才多艺
- 讨厌束缚、向往自由
- 思维跳跃、"跳跳兔"
- 难以忍受负面情绪

**高阶表现（健康1-3级）**
- 充满热情的冒险家
- "深化体验"——不只是收集，是深度参与
- 把快乐变成分享

**低阶表现（不健康7-9级）**
- 逃避现实、上瘾
- 肤浅、多嘴多舌
- "多动症"——停不下来

**典型语言**
> "太棒了！"
> "我们试试这个！"
> "没有我做不到的"

**Wing（侧翼）**：8号 wing
**Arrow（发展路径）**：压力下变成1号，轻松时变成5号

**最容易踩的坑**：用"我乐观"来逃避负面情绪、不面对痛苦

### Type 8: 保护者（The Challenger / Boss）

**位置**：腹中心 → 位置4

**核心动机/恐惧/欲望**
- 动机：我必须保护自己和身边的人
- 恐惧：被控制、被侵犯
- 欲望：保护自己、能力、掌控

**行为特征**
- 强势、有领导力
- 保护身边的人
- 讨厌被控制
- 直来直去、坚硬
- "硬的壳，软的心"

**高阶表现（健康1-3级）**
- "家长式的爱"——保护而不是控制
- "温柔的力量"——强大但不欺压
- "授权者"——帮助别人变强

**低阶表现（不健康7-9级）**
- 暴君、控制狂
- 报复、残忍
- "碾压所有不同意见"

**典型语言**
> "我来处理"
> "听我的"
> "没有人能伤害你"

**Wing（侧翼）**：7号 wing
**Arrow（发展路径）**：压力下变成5号，轻松时变成2号

**最容易踩的坑**：把"保护"变成"控制"，不允许别人成长

## Wings（侧翼）：更精细的类型

除了核心类型，每个人还有一个"侧翼"——相邻的类型会轻微影响核心类型。

**说明**：
- **左翼（Lower Wing）**：数字小的相邻类型（如1号的左翼是9号）
- **右翼（Upper Wing）**：数字大的相邻类型（如1号的右翼是2号）

**例子**：
- "1号带7号翼"（1w7）= 更乐观的完美主义者（左翼9右翼2之外的影响）
- "4号带5号翼"（4w5）= 更内���的浪漫主义者

| 核心类型 | 左翼（数字小） | 右翼（数字大） |
|----------|---------------|----------------|
| 1号 | 9号 | 2号 |
| 2号 | 1号 | 3号 |
| 3号 | 2号 | 4号 |
| 4号 | 3号 | 5号 |
| 5号 | 4号 | 6号 |
| 6号 | 5号 | 7号 |
| 7号 | 6号 | 8号 |
| 8号 | 7号 | 9号 |
| 9号 | 8号 | 1号 |

**侧翼特征**：侧翼通常比核心类型更明显地表露在外。

## Arrows（压力/轻松线）：发展路径

- **压力线（Stress Line）**：在压力状态下，会表现得像箭头指向的类型

**箭头走向**：

     ↘   ↙

## 分析流程

### Step 1: 确定核心类型

通过对以下问题的回答，推断核心类型：

1. **最深的恐惧是什么？**（核心恐惧）
2. **最强烈的动机是什么？**（核心动机）
3. **最想要的是什么？**（核心欲望）
4. **在压力下会怎么反应？**（压力反应）
5. **习惯怎么处理冲突？**（行为模式）

### Step 2: 判断 Wings

观察：
- 外在表现更偏向哪个相邻类型？
- 哪个侧翼更容易被观察到？

### Step 3: 评估层级

- 健康状态（1-3级）有哪些表现？
- 一般状态（4-6级）有哪些表现？
- 不健康状态（7-9级）有哪些倾向？

### Step 4: 交叉验证

- 动机和恐惧是否匹配某一类型？
- 行为模式和描述是否一致？
- 箭头路径是否符合发展轨迹？
- 可参考 references/03_quick_ref.md 中的"常见误判纠正"表做排除验证
